## Evidence Classes & Epistemic Boundaries

Evidence in this repository is strictly segregated into distinct classes. Results across these classes must **NEVER** be collapsed or aggregated into a single combined PASS count:

1. `LIVE_EMPIRICAL`: Observations from proven, independent, live subject agent execution sessions.
2. `DETERMINISTIC`: Mechanically computed filesystem, cryptographic, or validator test results.
3. `STATIC`: Static analysis, structural schema checks, or codebase property verifications.
4. `SPECIFICATION`: Formal consistency models, bounds, or specification matrices.
5. `SYNTHETIC_SIMULATED`: Synthetic fixture runs, mocked traces, or simulated model behaviors.
6. `INFERENCE`: Deductive or analytical assessments derived from bounded evidence.
7. `UNKNOWN`: Unverified or environment-constrained states.
