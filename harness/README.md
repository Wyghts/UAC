# UAC Deterministic Validation Harness

This directory contains deterministic fixture builders, validators, automated verification oracles, and regression tools.

## Epistemic Integrity Mandate
- **No Synthetic Conflation**: Synthesizing, mocking, or predicting an agent's response and labeling it as live-agent behavioral evidence is strictly prohibited.
- **Deterministic First**: Harness tools must compute exact mechanical invariants, cryptographic hashes, line counts, and validator exit codes.
