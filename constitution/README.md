# UAC Constitution Directory

This directory houses frozen baseline versions and working candidate texts of the Ultimate Agent Constitution (UAC).

## Rules of Record
- Frozen releases represent historical and active governance baselines (e.g. `vFinal.2e`).
- Working candidate variants represent isolated hypotheses under controlled empirical testing.
- **Candidate commit $\neq$ promotion**: Placing a candidate in this directory does not deploy or activate it for live governance.
